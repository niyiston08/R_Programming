If missing values found, will be replaced. For numeric variables, we use the median, and for categorical variables, we use the most common value. If there are no missing values, no replacement is needed.

# Replace missing values in numeric columns with the median
data <- data %>%
  mutate(across(where(is.numeric),
                ~ ifelse(is.na(.x), median(.x, na.rm = TRUE), .x)))

# Replace missing values in categorical columns with the most common value
mode_value <- function(x) {
  ux <- unique(x[!is.na(x)])
  ux[which.max(tabulate(match(x, ux)))]
}

data <- data %>%
  mutate(across(where(is.character),
                ~ ifelse(is.na(.x), mode_value(.x), .x)))

Five Practical Recommendations for Policymakers

  1. Improve the economy: Create jobs, support businesses and improve people’s skills to increase income and living standards.

  2. Fight corruption: Promote transparency, accountability and better public services to build trust in government.

  3. Improve healthcare: Provide better healthcare services, mental-health support and healthy living conditions.

  4. Strengthen social support: Encourage community support, reduce inequality and help vulnerable people.

  5. Protect freedom: Promote citizens’ rights, participation in decision-making and freedom to make personal choices.
